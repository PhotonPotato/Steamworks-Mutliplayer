# Steamworks-Multiplayer
Host and join multiplayer lobbies through Steam using FacePunch's [C# Steamworks Wrapper](https://wiki.facepunch.com/steamworks/).
Clean first-person player movement.
Runs a dedicated server and client concurrently off of the lobby host.

## To Build
***Major note**: you can't connect to Steam lobbies through my game if you aren't on the app's whitelist. Hmu if you want to be added or have questions. \
If you have Unity Editor version 6 or higher, you should be able to make a fresh build using the following steps:
- File -> Build Profiles
- Choose your desired platform
- Build or Build and Run
- Executable will be in the named folder
<br>


This repo will be used to learn and test the usage of a true dedicated server in the near future.
